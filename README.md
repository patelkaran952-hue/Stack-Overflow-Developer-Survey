# Stack Overflow Developer Survey 2025 – End-to-End Data Analytics & Machine Learning Project

## Project Overview

This project analyzes the **Stack Overflow Developer Survey 2025** dataset to uncover insights about developers, technologies, salaries, AI adoption, and industry trends. The project covers the complete data analytics lifecycle—from cleaning raw survey data to building machine learning models, recommendation systems, clustering, NLP analysis, association rule mining, and interactive dashboards.

The objective was to transform a complex, real-world survey dataset into actionable insights while demonstrating professional data analytics and machine learning skills.

---

## Dataset

* **Source:** Stack Overflow Developer Survey 2025
* **Records:** ~49,000 developer responses
* **Features:** 170+ survey columns
* **Domain:** Software Development & Technology

---

## Project Objectives

* Clean and preprocess a real-world survey dataset
* Standardize inconsistent categorical responses
* Engineer meaningful developer profile features
* Perform exploratory data analysis (EDA)
* Discover developer personas using clustering
* Build a technology recommendation system
* Predict developer salaries using regression models
* Analyze developer text responses with NLP
* Discover technology relationships using Association Rule Mining
* Create interactive dashboards for business insights
